# Toilet Fertilizer settings

Settings live in `BepInEx\config\com.dev.survivallog.toiletfertilizer.cfg`, created the first time the game starts with the mod. Change them in game on the Mod Manager's Mods screen, where they take effect right away, or edit the file while the game is closed. Delete the file to get the defaults back. Each world can have its own `Fertilizer` and `Amount`. Pick them for a new world in Customizable Difficulty, or change them on the Mods screen while you play, which changes them for that world only.

## Reward

| Setting | Default | What it does |
| --- | --- | --- |
| `Fertilizer` | `Basic` | Which fertilizer the toilet gives: `Basic` (Basic Fertilizer), `Compound` (Compound Fertilizer) or `PremiumOrganic` (Premium Organic Fertilizer, the best one). Without the mod the toilet gives `Basic`. |
| `Amount` | `2` | How much fertilizer each toilet use gives, from 1 to 20 (one full stack). Without the mod the toilet gives 2. |

The defaults give 2 Basic Fertilizer, the same as without the mod. For the best fertilizer and twice as much, set `Fertilizer` to `PremiumOrganic` and `Amount` to `4`.
